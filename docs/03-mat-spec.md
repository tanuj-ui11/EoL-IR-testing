# Non-conducting mat

Purpose: insulate the operator and the fixture from earth so a fault cannot route through the operator.

Requirements (starting point, to be confirmed with the vendor/safety review):
- Insulating rubber mat to **IEC 61111 Class 0 or better** (5 kV AC proof test; Class 0 is rated for use up to 1 kV AC). Class 1 gives more margin against the 3 kV test level.
- Thickness about 3 mm or more, smooth anti-slip surface, no punctures or conductive dust ingress.
- Size at least 600 × 450 mm under the fixture, plus a mat where the operator stands (at least 900 × 600 mm).
- Marked with class and test date; inspect before each shift. Replace if cut, cracked or contaminated.
- The existing green mat in the photos is **unrated or unknown**. Don't rely on it until it has a datasheet or has been tested.
- Keep the mat clean and dry, and don't coil leads over its edge.
